Change Log

Changes/Additions to Central Automation Studio over time. Newest updates at the top.

Version 2.8.0 (2026/11/08)

  • Added WLANs Statistics page
  • Added support for configuring the Context Delivery Service
  • Various minor bug fixes

Version 2.7.9 (2026/10/28)

  • Added support for IGMP Proxy in VLANs
  • Added support for editing VLANs via UI Editor
  • Various minor bug fixes

Version 2.7.8 (2026/09/28)

  • Site Assignment supported via CSV Workflows

Version 2.7.7 (2026/09/14)

  • JSON editor now uses Monaco Editor for proper JSON handling (not just text)

Version 2.7.6 (2026/08/19)

  • Added support for deleting WLAN, RF and AP System profiles that are not assigned to any scope

Version 2.7.5 (2026/07/17)

  • Added JSON Editor support for Interface VLAN (Layer 3) inside the VLAN page
  • Added support SA Query Timer in the WLAN UI Editor
  • Added new features to the Clients Statistics page
    • Additional Client Type views - Operating System, Manufacturer, Category, Vendor, Function, Tags
    • Added Client VLAN Distribution graph

Version 2.7.4 (2026/07/06)

  • Added Mesh Topology long-link RF profile impact analysis and RF profile update workflow

Version 2.7.3 (2026/07/04)

  • Added configuration support for Mesh Profiles
  • Added Mesh Max Distance to the RF Profile

Version 2.7.2 (2026/07/03)

  • Added Geo Map view to Mesh Topology with AP location plotting and distance overlay
  • Added Pathloss overlay to Mesh Topology using link radio MAC pathloss lookups
  • Enhanced Mesh Topology with new link details view opened from Mesh topology link double-click
    • Added 3-column layout with Mesh Parent details, RF trend graphs, and Mesh Child details
    • RF trend graphs: Throughput, Frames, Channel Utilization, Noise Floor, and Channel Quality

Version 2.7.1 (2026/06/28)

  • Under-the-hood reliability improvements to Central API proxy/auth handling
  • Improved retry behavior and internal stability across configuration and monitoring workflows

Version 2.7.0 (2026/06/22)

  • Added Mesh Topology monitoring page for Portal APs
    • Added overlay modes and directional link details for mesh links
  • Added Client Channel Distribution chart to Client Statistics
    • Shows client count per wireless channel for the selected band
    • Band selector supports 2.4 GHz, 5 GHz (default) and 6 GHz
    • Clicking a bar opens the filtered client list for that channel
  • Improvements to Floorplans
    • Added Radar and Pathloss overlays

Version 2.6.2 (2026/06/03)

  • Added Client Isolation knob to WLAN profile

Version 2.6.1 (2026/06/05)

  • Updated CSV Bulk configuration of device hostname (due to API changes)
  • Added support for FTM Scan knobs in RF profile
  • Improvements in AP and Switch monitoring

Version 2.6 (2026/05/07)

  • Added Floorplan support
    • AP Health
    • RF - Channels, Bandwidth, Utilization, Noise Floor
    • Clients - Device Types, Counts
  • Additional config options in AP System Profile
    • Barometer Sensor
    • Bypass Upstream Router (deny-local-routing)
    • DHCP Option 82
  • Added '40MHz Intolerance' knobs in RF profile
  • Added 'Disable on 6GHz Mesh' in WLAN profile

Version 2.5 (2026/05/01)

  • Added Sites support
    • Bulk Site creation using CSV

Version 2.4.1 (2026/05/01)

  • Added bulk assignment flows to WLAN, RF and AP System profiles (to match VLAN Profiles)

Version 2.4 (2026/04/28)

  • Added VLAN profile support
  • Added Site information download as CSV
  • Added Background Scanning knob in RF profile

Version 2.3.1 (2026/04/22)

  • Added extra Client Statistics (SNR, Authentication Types, MLO Mode)
  • Added extra AP Statistics (CPU, Memory and Negotiated Power)
  • Added extra SW Statistics (CPU, Memory, POE Consumption)
  • Added extra GW Statistics (CPU, Memory)
  • Minor bug fixes

Version 2.3 (2026/04/20)

  • Added Config Sets support
  • Changes in APIs used for monitoring data
  • Support for March 2026 improvements
    • Client Count per AP, Radio and BSSID
    • Client Cipher Suites
  • Multiple improvements in the statistics pages

Version 2.2.2 (2026/03/31)

  • Added AP Health Decoder
  • Added exporting from the Subscriptions table
  • Improved Error log

Version 2.2.1 (2026/03/21)

  • Added support for Authentication Survivability in WLAN profiles using Bridge Mode
  • Improved support for removing description from profiles
  • Improvements in CSV workflows
    • Support for CNX CSV export format
    • Removed expired licenses from the license dropdowns
    • Improved logging
  • Other minor fixes

Version 2.2 (2026/03/14)

  • Added support for assigning devices to Central and licensing devices in CSV Workflows.
  • Minor fixes

Version 2.1.1 (2026/03/05)

  • Fixes for CSV workflows (due to API changes)
  • Added CSV downloads from Device Lists

Version 2.1.0 (2026/03/03)

  • Migrated MRT API calls to v1 API
  • Improved UI consistency and look and feel
  • Statistics pages include more information (with Filters)
  • Added verification of selected Central cluster when adding account
  • Many bug fixes
  • Added support for "Denylist - Security Context Override Attack" in WLAN profiles

Version 2.0.3 (2026/02/10)

  • Client Statistics now available (limited data so far)
  • Dashboard tiles for Statistics (also available from link in overview tiles)
  • Client counts now available in the Multiple Account dashboard
  • Updated icons

Version 2.0.2 (2026/02/09)

  • AP System Profiles support has been added
  • Minor fixes for WLANs and RF profiles

Version 2.0.1 (2026/02/05)

  • FTM Scans has been renamed to "AP Ranging Scans"
    • AP Ranging Scans now uses updated APIs
    • AP Ranging Scans now supports stopping a Pending scan

Version 2.0.0 (2025/12/13)

  • Initial launch of Central Automation Studio 2.0.0

Version 2.0.0.a (2025/02/04)

  • Soft launch of Central Automation Studio 2.0.0 alpha

The Docker container includes this WebUI and a single API Proxy inside the same container, allowing for private use.
