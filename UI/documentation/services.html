Services

Device Inventory

The Device Inventory page displays a table of all networking devices in the GreenLake device inventory.

Page provides simple tiles to filter the device inventory based on the licensing state of the device or if the device is not yet assigned to Aruba Central

The page provides a CSV download of the filtered devices table, which can be used with CSV workflows within Central Automation Studio


Context Delivery

The Context Delivery page allows the configuration of the Context Delivery Service.

The Context Delivery Service enables syncing Dynamic Client Denylist, and Authentication Survivability cache between all APs within a site.
